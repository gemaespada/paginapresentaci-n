## 🚀 Cómo visualizar el proyecto localmente

Puedes abrir la web directamente de cualquiera de estas dos formas:

1. **Doble clic en `index.html`:** Ábrelo con cualquier navegador web moderno (Chrome, Safari, Firefox, Edge).
2. **Servidor local (recomendado):**
   ```bash
   python3 -m http.server 8080
   ```
   Y accede a `http://localhost:8080` desde tu navegador.
