# Gema Espada | Desarrollo Web Full Stack en formación

Web personal minimalista y responsive (HTML, CSS y JavaScript) con tonos azules, blancos y neutros.

## Secciones
1. **Inicio**: presentación y botones «Conoce mi formación» y «Hablemos de tu idea».
2. **Sobre mí**: trayectoria desde la Educación Primaria Bilingüe hacia el desarrollo web.
3. **Formación y conocimientos técnicos**: estudios, módulos completados del máster y conocimientos por grupos.
4. **Certificaciones**: Pseudocódigo, Python, Linux y la Terminal, Git y GitHub, Python avanzado.
5. **¿Tienes una idea para tu web?**: invitación a conversar, enlaza a Contacto.
6. **Contacto**: correo, LinkedIn, GitHub y formulario.

## Ver en local
Abre `index.html` en el navegador, o ejecuta `python3 -m http.server 8080` y visita `http://localhost:8080`.

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: estilos y diseño responsive.
- `script.js`: menú móvil, sección activa, aparición suave y formulario.
